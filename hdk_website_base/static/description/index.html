Hamdek Sale Base

Foundation module for Hamdek Sales Pro. It adds a dedicated Hamdek Sales Configuration section inside Odoo Sales settings so related modules can group their options in one clear place—without cluttering the standard stock settings layout.

Key Features

Dedicated Settings Block

A visible Hamdek Sales Configuration block appears under the Sales app in Settings, ready for Hamdek modules to extend with toggles, help text, and links.

Consistent UX

Matches the same pattern as Hamdek Sales and Purchase base modules: one branded area per app so administrators always know where to look for Hamdek-specific behaviour.

Lightweight & Safe

Only depends on Stock. No business logic on its own—safe to install as a prerequisite for other Hamdek Sales modules without changing transfers or stock levels.

Extensible by Design

Child modules inherit this view and inject their own fields inside the same block, keeping documentation and screenshots aligned across your Hamdek Sales suite.
