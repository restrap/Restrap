Hamdek Website Login Gate

Turn your storefront into a members-only website, or keep it open and only require sign-in for cart, checkout, or selected menus—all per website from Hamdek Website Configuration in Settings.

Why use it

One module for website access control: optional full-site login, block cart actions until login, redirect guests away from checkout with a cart-style notification, and hide navigation for anonymous visitors—without custom templates.

One settings panel

Per website: toggles and menu picks live under Website → Settings → Hamdek Website Configuration.

Same cart notifications

Restricted add-to-cart and checkout flows use the familiar shop warning toast—not a separate checkout login page.

Reliable login screen

When full-site login is on, the classic email/password form is shown on /web/login so the page never stays blank.

Key Features

Browse / login gate

Optional: require sign-in before any storefront page; signup, password reset, TOTP, and payment return URLs stay available.

Cart & checkout rules

Optional: require login to add or change cart contents; optional: require login at checkout (redirect to cart + notification).

Menus hidden for visitors

Multi-select website menus to hide from logged-out users (children hidden with the parent).

Hamdek Website Base

Shared “Hamdek Website Configuration” section so other Hamdek apps can extend the same block.

How to Get Started

  1. Install Hamdek Website Base and Hamdek Website Login Gate (hdk_website_login_gate).
  2. Open Settings → Website, select your website, then Hamdek Website Configuration.
  3. Enable the rules you need and test in a private browser window as a guest.
